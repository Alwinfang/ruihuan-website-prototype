# Ruihuan Website Prototype

Static English website prototype for Dongguan Ruihuan New Materials Technology Co., Ltd.

## Run locally

```powershell
python -m http.server 4173
```

Open `http://localhost:4173`.

## Content boundaries

- Product categories, listed grades, contact details, company name and location are based on the supplied materials.
- Certification claims, current delivery commitments, factory metrics, technical documents and packaging details are intentionally not presented as confirmed facts.
- Images in `assets/images/` are approved user-provided materials, generated visuals or attributed external images noted in `assets/images/SOURCES.md`.

## GitHub Pages

Publish the repository root from the `main` branch through GitHub Pages. No build step is required.
